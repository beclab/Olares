# 安装、卸载和更新

本文档介绍如何安装、更新和卸载应用，以及如何安装自定义应用。

## 查找应用

打开应用市场后，默认进入**发现**页面。页面包含精选推荐、社区推荐、最受欢迎应用、最新应用等版块，也可以按设计创作、工作效率、休闲娱乐、生活方式、实用工具、开发工具、AI 等类别浏览应用。

![应用市场](/images/manual/olares/market-discover-1.png#bordered)

要查找特定应用，在左侧**管理**子菜单中点击**搜索**，输入关键词，相关结果将随输入实时显示。

![搜索应用](/images/manual/olares/search-app.png#bordered)


### 切换应用源 

你可以选择不同的应用商店源，以加快浏览、搜索和下载应用的速度，或者安装某些源特有的应用。要切换应用源：
1. 打开**应用市场**，从左侧导航栏进入**我的 Olares** > **设置**。
2. 在**市场来源**下，点击**添加源**以添加新的应用源。当前 Olares 官方源包括：
   - 国际源：https://api.olares.com/market   
   - 国内源：https://api.olares.cn/market
3. 按要求填写源标题、URL、以及描述后，点击**确认**完成添加。 
4. 在源列表中，选择您希望使用的源以将其激活。等待大约 10 分钟，商店页面就会更新到新的源。

::: tip 注意
不同安装源在**我的 Olares**页面会生成相应的页签，以便于管理应用。
:::

## 安装应用

要从应用市场安装应用：

1. 从程序坞或启动台打开**应用市场**，双击目标应用查看详情。
2. 如果应用支持多种硬件加速器，在**资源**区域选择计算资源，并确认当前硬件满足列出的 **CPU**、**内存**、**所需磁盘空间**和**显存**要求。

    ![加速器](/images/zh/manual/olares/market-accelerator1.png#bordered)

3. 点击**获取**，然后点击**安装**。
4. 如果应用需要设置环境变量，在弹出的窗口中完成设置：

    ![设置环境变量](/images/manual/olares/set-app-env-var.jpeg#bordered)

    - **自定义变量**：直接在弹窗中输入值。
    - **引用的系统变量**：先前往**设置** > **开发者** > **系统环境变量**页面设置对应变量的值，然后返回继续安装。

5. 安装完成后，按钮将变为**打开**，点击即可启动应用。

管理员在应用市场中安装共享应用，安装方式与普通应用相同。安装后，启动台会出现相应的应用入口，集群成员无需自行安装，直接点击入口即可使用。详见[共享应用](shared-apps.md)。

## 安装模型

应用市场提供两种运行本地大语言模型（LLM）的方式：

- **预打包模型应用**：由官方打包、经过验证的模型与引擎组合，安装方式与普通应用相同：在应用市场找到应用，点击**获取**，然后点击**安装**。
- **使用引擎基座运行自定义模型**：Olares v1.12.6 引入了引擎基座（Engine Base）应用，即基于 Ollama、vLLM、SGLang、llama.cpp 等推理引擎的模板应用。将基座应用克隆为独立的模型实例，自行配置模型来源和参数。

模型实例属于共享应用。多用户集群中，只有管理员需要安装模型实例，集群成员无需安装即可直接使用。

要通过引擎基座创建模型实例：

1. 在应用市场搜索"Engine Base"，打开所需引擎基座的应用页面。
2. 点击**创建**，选择硬件加速器，并为实例设置唯一名称。

    ![创建模型实例](/images/manual/olares/llm-base-apps-create-instance2.png#bordered)

3. 配置模型来源等环境变量，完成实例创建。

安装完成后，打开应用即可进入模型控制台。模型文件会自动下载，下载完成且模型就绪后，服务才会对外开放 API 端口供客户端调用。在 **Status** 页签中，**Model** 状态显示 `Ready` 即表示可以对外提供服务。

完整的配置说明，参见[使用 Engine Base 运行本地大模型](/zh/use-cases/llm-base-apps.md)。

## 更新应用

从应用市场下载的应用可按以下步骤获取更新：

1. 打开**应用市场**。
2. 在左侧边栏**管理**子菜单下点击**更新**。如果有更新可用，将显示标记数字。
3. **可用更新**页面会列出可更新应用。点击**全部更新**以一次性更新所有应用，或单独更新每个应用。

## 查看应用操作日志

应用操作日志详细记录了应用在市场里的安装、下载、更新和卸载等操作的过程与状态。要访问这些日志：

1. 打开**应用市场**。 
2. 从左侧边栏进入**我的 Olares**。 
3. 页面右上角点击**日志**以进入具体日志页面。

你可以点击 <i class="material-symbols-outlined">download</i> 按钮以下载这些日志以进一步分析。

## 常见问题

### 为什么我无法安装应用？

如果无法安装应用，可能是由于以下原因：
* **系统资源不足**：尝试释放系统资源，或增加资源配额。
* **缺少依赖项**：在应用详情页在检查是否已安装所需依赖项。
* **系统版本不兼容**：尝试将 Olares 升级到最新版本。
* **共享应用依赖**（对于 Olares 成员）：该应用需要集群中已运行某个共享服务。请联系管理员先安装相应的共享应用，然后你才能安装此应用。

如需根据具体症状排查并收集操作日志，请参考[应用安装、更新期间或之后失败](../../help/ts-app-fails-after-update.md)。

### 为什么应用处于停止状态？

应用停止运行通常是由于以下原因之一：
* **系统自动停止**：为了保障 Olares 的稳定性，系统会持续监控资源使用情况。如果某个应用瞬间占用了过高的资源（如 CPU 或内存），导致系统负载过高，系统可能会自动暂停该应用，以防止整个设备卡顿或崩溃。
* **手动停止**：你或管理员此前可能手动停止了该应用，且尚未进行恢复操作。

### 为什么我现在无法恢复应用？

启动应用需要预留一部分固定的计算资源。如果当前运行的其他应用已经占用了大部分资源，剩余的“空闲资源”就不够分配给你想要启动的这个应用了。

因此，当你尝试恢复应用时，可能会遇到以下提示，这种情况下，你需要先关闭其他应用以释放资源：
| 错误提示 | 说明 |
| :--- | :--- |
| 系统 CPU/内存资源不足 | 整个系统的物理资源已接近耗尽。 |
| 系统存储空间不足 | 硬盘空间已满，无法写入新数据。 |
| 可用 CPU/内存不足 | 虽然系统仍有少量资源，但无法满足此应用启动所需的最低配置。 |

### 如何恢复应用？

要恢复该应用，你需要释放一些被占用的资源：

1. 进入**设置** > **应用**，查看当前状态为**运行中**的应用。
2. 找到你暂时不需要使用的应用。
3. 点击该应用，然后点击**暂停**以关闭运行状态，从而停止该应用。
4. 资源释放后，回到你原来的应用，再次点击**恢复**。

### 如何释放未使用应用的资源？

如果某些应用暂时不使用，且你希望释放它们占用的系统资源，可以通过应用市场或设置停止这些应用。

<template #从应用市场暂停应用>

2. 在左侧边栏中，点击**我的 Olares**。使用源选项卡筛选并找到要停止的应用。
3. 点击应用操作按钮右侧的 <i class="material-symbols-outlined">keyboard_arrow_down</i>，然后选择**暂停**。

#### 释放共享应用的资源

要完全释放共享应用的资源（如 Ollama 等），必须停止服务端服务。此操作只能由管理员执行。

当管理员停止共享应用时，将出现 **同时停止共享服务器（影响所有用户）** 复选框：
- 要完全释放资源，必须勾选此复选框。
- 勾选后，该服务将在整个集群中被禁用，其他用户也将无法再使用该应用。
- 此复选框仅在多用户集群中出现。在单用户场景下，系统默认会自动同时停止用户端应用和服务端服务。

:::info 针对 Olares V1.12.4 及更早版本的说明
在 Olares 1.12.4 及更早版本中，若要完全释放资源，必须使用应用市场：
- 在应用市场中暂停应用，并确保已勾选 **同时停止共享服务器（影响所有用户）** 选项。
- 如果已经通过**设置**停止了用户端应用，必须先在应用市场中将其恢复，然后再停止该共享应用，并确保已勾选 **同时停止共享服务器（影响所有用户）** 选项。
:::

### 升级到 V1.12.6 后，我之前安装的旧版共享应用会怎样？

Olares 1.12.6 引入了全新的 V3 共享应用架构。旧版 V2 共享应用仍可继续启动、停止、暂停和恢复，但无法直接升级到 V3。如需使用 V3 版本，必须先卸载 V2 版本，再安装 V3 版本。已有数据需要手动迁移。

有关架构变更和迁移流程的完整说明，请参考 [共享应用](shared-apps.md)。
