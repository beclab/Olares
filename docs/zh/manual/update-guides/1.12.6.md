# 更新到 Olares 1.12.6 后需要做什么

Olares 1.12.6 调整了部分应用的架构和使用方式。

本文列出了可能受影响的应用和使用场景。你可以先查看下表，找到与自己相关的情况，再按需处理。

:::warning 迁移或重装应用前
需先查看应用的迁移指南，并按说明备份或导出数据。卸载旧应用时，谨慎选择**同时删除所有本地数据**。该选项可能永久删除模型、工作流、设置或其他应用数据。
:::

## 查看适用情况

| 遇到以下情况 | 建议处理方式 |
| --- | --- |
| 曾在 Olares 1.12.6 之前安装共享应用 | 先确认应用是否采用旧架构。如果是，可按迁移指南处理数据后再卸载。[查看迁移方式](#_1-12-6-之前安装的共享应用)。 |
| 更新后，原有 AI 应用无法启动 | 备份所需的应用数据并卸载旧版本，然后从应用市场安装最新兼容版本。[了解详情](#无法启动的-ai-应用)。 |
| 正在使用独立 Ollama 应用 | 无需立即处理。以后部署新模型时，需改用 Ollama 引擎基座。[查看使用方法](#改用-ollama-引擎基座)。 |
| 正在使用 Sonarr、Radarr、Prowlarr 或独立下载客户端 | 根据 1.12.6 的变化更新相关连接 URL 和路径。[查看具体变化](#arr-应用和下载客户端)。 |
| 之前使用过 Studio | 改用当前的 Agent Skills 和应用提交指南。[查看替代方案](#studio-的替代方案)。 |

## 1.12.6 之前安装的共享应用

Olares 1.12.6 之前，共享应用采用服务端与客户端分离的架构。本文将这类应用称为 v2 共享应用。更新后，原有 v2 共享应用仍可继续使用，但无法直接升级到新架构。从 Olares 1.12.6 开始，每个共享应用都以单一服务的形式运行，并由管理员统一管理。详情参见[共享应用](/zh/manual/olares/market/shared-apps#了解架构变化)。

如需判断应用是否为 v2 版本，可打开应用市场中的应用详情页，查看**信息** > **兼容性**。v2 应用通常显示 `Olares >=1.12.3-0, <1.12.6`，新版应用则显示 `Olares >=1.12.6-0`。

**选择迁移方式**

- **保留本地数据**：迁移 ComfyUI 时，卸载旧应用但不要删除本地数据，然后安装新版本。具体步骤参见 [ComfyUI 迁移说明](/zh/use-cases/comfyui-common-issues#升级到-olares-1126-后如何迁移到新版-comfyui)。
- **按应用指南迁移**：Dify、OnlyOffice、SearXNG 和 Xinference 可保留的数据不同。可查看对应的 [Dify](/zh/use-cases/dify-upgrade)、[OnlyOffice](/zh/use-cases/onlyoffice-migration)、[SearXNG](/zh/use-cases/searxng) 或 [Xinference](/zh/use-cases/xinference) 迁移指南。
- **直接重新安装**：仅适用于没有用户数据需要迁移的应用。操作方法参见[共享应用](/zh/manual/olares/market/shared-apps#选项二-重新安装)。

## 改用 Ollama 引擎基座

从 Olares 1.12.6 起，独立 Ollama 应用已从应用市场下架。已经安装的应用仍可继续使用，但无法通过应用市场更新。

部署新模型时，需使用 **Ollama 引擎基座**：

1. 在 Ollama 引擎基座上部署模型。
2. 在模型控制台中打开该模型，复制用于连接客户端应用的 **Base URL**。
3. 修改原有客户端的配置，将其连接到新的 Base URL。

完整设置步骤参见[运行本地大模型](/zh/use-cases/llm-base-apps)。

## Studio 的替代方案

Studio 原用于在真实的 Olares 环境中创建、移植、打包和测试应用。目前 Studio 已从应用市场下架，相关文档也已停用。

可根据需要查看以下文档：

- [安装与使用 Agent Skills](/zh/developer/cli-agent-skills)：了解 Olares CLI 技能包，包括 `olares-chart`。
- [提交应用](/zh/developer/develop/submit-apps)：了解目前的应用市场提交流程。

## 其他可能与你有关的变更

### 无法启动的 AI 应用

更新后，部分在 1.12.6 之前安装的 AI 应用可能无法启动。如果遇到这种情况，需卸载旧版本，再从应用市场安装最新兼容版本。如果已经在 1.12.6 候选版本（RC）期间重新安装过该应用，无需再次处理。

如果应用中有用户数据，可在卸载前查看迁移指南，并按说明保留数据。

### *Arr 应用和下载客户端

Olares 1.12.6 调整了 *Arr 应用的连接方式和存储路径：

- **连接**：*Arr 应用改用内部入口 URL 通信，不再使用提供商 URL。
- **路径**：*Arr 应用和下载客户端改用统一的挂载目录结构。

可按照 [*Arr 应用升级说明](/zh/use-cases/arrs-upgrade)更新相关 URL 和路径。如果使用独立下载客户端，还需查看[下载客户端升级说明](/zh/use-cases/download-clients-upgrade)。

## 可选：启用 Olares One 自动开机

**自动开机**开关位于**设置** > **我的 Olares** > **我的硬件**。启用后，连接电源或断电恢复时，Olares One 会自动启动。

该功能需要 Olares OS 1.12.6 或更高版本，以及嵌入式控制器（EC）固件 1.03 或更高版本。版本不符合要求时，该开关不可用。检查或更新 EC 固件的方法参见[管理 BIOS 和 EC](/zh/one/update-firmware)。
