<!-- #region export-system-logs-steps -->
1. Open Olares Settings, and then go to **Advanced** > **Export system logs**.
2. Click **Collect** to generate the log file. After collection completes, the log file appears in **Collection history**, and it is saved to the `Home/pod_logs` directory.

   ![Generate logs](/images/manual/olares/export-log2.png#bordered){width=65%}

3. In **Collection history**, click **Open** next to the generated log file to open the logs directory.
4. Right-click the log file and select **Download**.
<!-- #endregion export-system-logs-steps -->
