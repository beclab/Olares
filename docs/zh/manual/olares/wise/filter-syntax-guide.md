# 过滤语法参考

你可以组合参数和运算符，为 Wise 过滤视图编写查询条件。

## 查询结构

单个条件使用`参数:值`格式。例如：

```
feed_id:12345
```

你也可以使用逻辑运算符组合多个条件。

### `AND`

使用 `AND` 要求结果同时满足所有条件。例如，查找未读且已加入**稍后阅读**的内容：

```
location:readlater AND seen:false
```

### `OR`

使用 `OR` 查找满足任一条件的内容。例如，查找已保存的内容，或最后打开时间早于 2023 年 1 月 1 日的内容：

```
islibrary:true OR last_opened__lt:2023-01-01
```

### 使用括号分组

使用括号 `()` 控制条件的组合方式。例如，查找位于**收件箱**或**稍后阅读**中的未读内容：

```
seen:false AND (location:inbox OR location:readlater)
```

### 特殊字符

如果条件值包含空格、冒号等特殊字符，请用半角双引号将其括起来。例如：

```
tag:"Project/AI"
```

```
author:"Arthur C. Clarke"
```

## 参数

### 基本参数

使用`参数:值`格式按内容属性筛选。

#### `feed_id`

内容所属订阅源的 ID。可以在**设置** > **RSS 订阅源**中编辑订阅源，查看其 ID。

#### `author`

内容的作者。

#### `file_type`

内容的文件类型。可用值包括：

- `article`
- `video`
- `audio`
- `ebook`
- `pdf`

### 时间参数

使用`参数__运算符:值`格式筛选时间。日期须写为 `YYYY-MM-DD`。

#### `published_at`

内容的发布时间。

#### `created_at`

内容的创建时间。

#### `updated_at`

内容的最后更新时间。

#### `last_opened`

内容的最后打开时间。

#### 运算符

可用运算符包括：

- `__gt`：晚于指定日期。
- `__gte`：等于或晚于指定日期。
- `__lt`：早于指定日期。
- `__lte`：等于或早于指定日期。

### 布尔参数

使用`字段名:true/false`格式，按条件是否成立筛选。

#### `islibrary`

内容是否已单独保存，例如是否已加入**收件箱**或**稍后阅读**，或通过**保存到库**收藏。这里的“库”指保存状态，不是侧边栏的**库**分组。

#### `isfeed`

内容是否来自订阅源。

#### `seen`

内容是否已读。

### 位置参数

#### `location`

内容所在的位置。可用值包括：

- `all`：所有已保存的内容，包括收件箱和稍后阅读中的内容。
- `readlater`：标记为**稍后阅读**的内容。
- `inbox`：位于**收件箱**的内容。

### 相关内容参数

#### `has`

按内容是否带有指定的附加信息筛选。可用值包括：

- `note`：带有笔记。
- `tag`：带有标签。

#### `tag`

按标签名称筛选。

#### `tag_id`

按标签的唯一 ID 筛选。可以在**设置** > **标签**页面查看标签 ID。
