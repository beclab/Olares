# 使用 Wise 建立阅读资料库 <Badge type="tip" text="Olares 1.12.8+" />

用 Wise 可以收藏网页和文件、订阅感兴趣的网站，并集中阅读和整理这些内容。

## 安装 Wise

1. 打开应用市场，搜索“Wise”。
2. 点击**获取**，然后点击**安装**。
3. 从启动台打开 Wise。

## 收藏、阅读和整理内容

看到感兴趣的内容，可以先收藏；想持续关注某个网站，可以订阅它。之后再挑选要读的内容，按自己的习惯整理：

- **收藏网页和文件。** 浏览网页时使用 LarePass、在 Wise 中粘贴网页链接，或上传设备上的文件。参阅[在 Wise 中收藏网页和文件](./collect)。
- **关注来源更新。** 订阅 RSS 源后，新内容会出现在**订阅源**中。你可以直接打开，也可以将想保留的内容加入**收件箱**或**稍后阅读**。参阅[订阅和管理订阅源](./subscribe)。
- **阅读和整理。** 回到**收件箱**或**稍后阅读**继续阅读，添加笔记和标签，或通过搜索、过滤视图找回内容。参阅[阅读和整理 Wise 内容](./basics)。

如果 Wise 无法访问需要登录的网站，请参阅[为 Wise 管理 Cookie](./manage-cookies)。
