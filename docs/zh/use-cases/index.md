# 应用示例

应用示例是 Olares 上热门开源应用的端到端指南，涵盖本地 AI、私人媒体服务器、自托管工作空间和开发者工具。选择一个分类或通过关键词搜索，然后打开完整指南。

:::tip 已在自己的电脑上使用 AI Agent？
你可以让现有的 Agent 帮你配置应用、部署模型和排查 Olares 问题。按照[通过 AI Agent 使用 Olares CLI](../developer/cli-install.md)，在这台电脑上安装 Olares CLI 和 Agent Skills 并登录。也可以直接告诉 Agent：

```plain
安装 Olares CLI 和 Agent Skills，然后帮我登录，以便管理我的 Olares。
```

运行在 Olares 上的 Agent 应用已经内置 Olares CLI 和 Agent Skills，请按照所用应用的指南开始使用。
:::
