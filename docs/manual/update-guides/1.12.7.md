# What to do after updating to Olares 1.12.7

Olares 1.12.7 introduces Router and Lares, and changes how applications connect to models. The update does not affect your existing apps or data.

After updating, complete the following setup to use the new AI features.

## Install Router, Lares, and a model

Applications on Olares now reach models through Router. To get started:

1. Open **Market** and install **Router**.
2. Install **Lares**, the first-party agent for your personal cloud.
3. Install a local model. For most devices, **Qwen3.8-27B** is a good starting point.

   :::info Lares handles one task at a time
   While Lares works on a task, new requests wait in a queue and start automatically when the current task finishes. Local models share the accelerator through time-slicing, so a running task does not block your other apps. To run Lares and another agent at the same time, connect them to different models.
   :::

## Connect apps through Router

Tutorials for AI and third-party apps have been updated for the Router connection flow. In short, point the app at Router's Base URL and use `default-chat` as the model name, instead of connecting to a model's own endpoint. You can change the default model in Router without reconfiguring the app.

If you configured an app before 1.12.7, update its model connection settings the next time you use it.
