# 计费与支付

Olares 与 Stripe 合作提供安全的支付服务。账单和收据会通过邮件发送，方便你留存记录。如果在支付过程中遇到问题，请联系 Olares 团队获取帮助。

## 计费概览

### 计费项目

以下服务或产品需要付费：

| 项目 | 计费方式 | 说明 |
|---|---|---|
| **套餐订阅** | 按月订阅 | 付费套餐（如 **Basic**）的月费。**Free** 套餐无月费。 |
| **备份存储** | 后付费（按量） | 主机数据备份到公共存储。每月前 50 GB 免费，超出部分按结算周期结束时的使用量计费。 |
| **Cloudflare 网络流量** | 后付费（按量） | 通过公共链接访问自托管 Olares 时，公网用户与 Olares Space 之间经过 Cloudflare 网络（CDN/WAF/DDoS）的流量。每月前 50 GB 免费。 |
| **Olares Tunnel 流量（FRP）** | 后付费（按量） | Olares Space 与你的自托管 Olares 之间通过 Olares Tunnel（反向代理）转发的流量。每月前 50 GB 免费。 |

:::tip 避免流量费用
如需避免 Cloudflare 网络流量和 Olares Tunnel 流量费用，请通过 [LarePass VPN](../larepass/private-network.md) 访问 Olares，而不是使用公共链接。
:::

### 账单生成时机

以下操作会生成账单：

| 操作 | 计费结果 |
|---|---|
| **升级套餐** | 从 Free 升级到 Basic 时，结账环节会生成一笔费用。 |
| **备份数据到 Olares Space** | 备份存储用量按结算周期结束时计费。 |
| **通过公共链接访问 Olares** | 超出每月免费额度的 Cloudflare 网络流量和 Olares Tunnel（FRP）流量按实际用量计费。 |

### 月度扣费方式

Olares 采用月度计费周期。每月会生成一笔账单，包括基础订阅费以及当月产生的其他费用，如额外流量和存储费用等。

- **自动扣费**：首次付款时将授权自动扣费，第一次使用的支付方式将设为默认方式。要停止自动扣费，请前往**用量与账单** > **支付方式**，删除已保存的支付方式。
- **支付有效期**：账单需在 3 小时内支付，逾期未付将自动取消。

## 查看计划

查看当前订阅计划和账单周期。

1. 点击左侧导航栏的**用量与账单**。
2. 选择**套餐**标签页。

   ![套餐标签页](/images/how-to/space/billing_plan.png#bordered)

3. 查看以下信息：
   - **套餐**：当前订阅计划，例如 **Basic** 或 **Free**。要从 Free 升级到 Basic，请参阅[更改订阅计划](#更改计划)。
   - **账单周期**：支付方式、账单周期和总金额。
   - **明细**：费用明细。

## 更改计划

从 Free 升级到 Basic，获取更多流量、带宽和存储空间。

1. 点击左侧导航栏的**用量与账单**。
2. 选择**套餐**标签页。
3. 点击当前计划旁的**变更**。
4. 对比可用计划。例如，**Basic** 包含更多月度流量、更高带宽、区域 FRP 节点、Olares Space 存储空间以及优先邮件支持。
5. 将鼠标悬停在 **Basic** 上，然后点击**选择**。
6. 在结账面板中核对账户信息、支付方式和应付金额。
7. 点击**确认**完成升级。

:::info
- 账户余额会先抵扣。剩余金额将从已保存的信用卡中扣除。
- 更改计划后，将立即开始新的计费周期。
- 当前计费周期内未使用的套餐额度不予退还。
:::

查看最新计划权益和价格，请访问 [Olares Space plans](https://www.olares.com/space/plans)。

## 查看账单

查看和下载历史发票。

1. 点击左侧导航栏的**用量与账单**。
2. 选择**账单**标签页。
   ![账单标签页](/images/how-to/space/billing_invoices.png#bordered)
3. 查看账单列表。
4. 要下载账单，点击**操作**列中的 <i class="material-symbols-outlined">download</i>。下载的 PDF 包含发票编号、开具日期、到期日期、账单信息以及费用明细。

## 兑换优惠券

大部分优惠码可在**优惠券**标签页兑换。如果活动提供了其他兑换方式（例如绑定账号邮箱），请按照活动物料中的说明操作。

1. 点击左侧导航栏的**用量与账单**。
2. 选择**优惠券**标签页。
   ![优惠券标签页](/images/how-to/space/billing_coupon.png#bordered)
3. 在输入框中输入兑换码。
4. 点击**立即兑换**。

:::info
优惠券金额不可退款。
:::

## 管理支付方式

在**支付方式**标签页添加、更新或移除信用卡。

1. 点击左侧导航栏的**用量与账单**。
2. 选择**支付方式**标签页。
3. 要添加支付卡，点击**添加信用卡**，输入卡片信息，然后点击**保存**。
    :::info
    Olares Space 只支持添加一张信用卡。
    :::
4. 要更换已保存的支付卡，点击**编辑**，输入新的卡片信息，然后点击**保存**。
5. 要移除已保存的支付卡，点击**删除**。

   ![支付方式面板](/images/how-to/space/payment_methods.png#bordered)

## 常见问题

### 别人访问部署在 Olares 上的 WordPress 站点时，我会产生费用吗？

会的。当别人通过公共链接访问你的 Olares 服务时，可能产生两类流量费用：

- **Cloudflare 网络流量**：经过 Cloudflare 网络（CDN/WAF/DDoS）的流量。
- **Olares Tunnel 流量（FRP）**：通过 Olares Tunnel 转发到你自托管 Olares 的流量。

两类流量都有每月免费额度，超出后按量计费。如果不想产生这些费用，可以使用 [LarePass VPN](../larepass/private-network.md) 而不是公共链接。

### 账单金额不足 1 美元会怎样？

如果总账单金额不足 1 美元，系统不会产生扣费。该金额会计入余额，并累计到下期账单中。

### 如何处理负余额？

出现负余额并不一定意味着欠费。点击右上角的头像，选择**余额**，会打开**余额详情**页面，查看具体明细。如果确实有待付金额，请及时支付，以免服务中断。
