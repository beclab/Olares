# Olares 1.12.6 升级指南

Olares 1.12.6 引入了多项架构与工作流变更。

本指南将说明 1.12.6 版本对现有应用及工作流的影响，帮助你判断是否需要采取行动，并提供详细的步骤指引。

:::warning 迁移应用前
先打开应用对应的迁移指南，按要求备份或导出数据。卸载旧应用时，谨慎选择**同时删除所有本地数据**。该选项可能永久删除模型、工作流、设置或其他应用数据。
:::

## 检查是否需要执行操作

| 使用场景 | 建议操作 |
| --- | --- |
| 旧版 v2 共享应用 | 根据应用选择迁移方式。[查看迁移选项](#迁移旧版共享应用)。 |
| 独立 Ollama 应用 | 新部署改用 Ollama 引擎基座。[查看方法](#从独立-ollama-迁移到引擎基座)。 |
| Studio | 使用当前的 Agent Skills 和应用提交指南。[查看替代文档](#使用新的应用开发流程替代-studio)。 |

## 迁移旧版共享应用

Olares 1.12.6 采用由管理员集中管理的单一共享服务，替代原有的服务端和客户端分离架构。现有的 v2 应用仍可继续运行，但不能直接升级到新架构。

要识别 v2 应用，需打开应用市场中的应用详情页，检查**信息** > **兼容性**。v2 应用通常显示 `Olares >=1.12.3-0, <1.12.6`，而新版应用显示 `Olares >=1.12.6-0`。

**选择迁移方式**

- **保留本地数据**：迁移 ComfyUI 时，卸载旧应用但不要删除本地数据，然后安装新版本。参见 [ComfyUI 迁移说明](/zh/use-cases/comfyui-common-issues#升级到-olares-1126-后如何迁移到新版-comfyui)。
- **按应用迁移**：根据应用查看 [Dify](/zh/use-cases/dify-upgrade)、[OnlyOffice](/zh/use-cases/onlyoffice-migration)、[SearXNG](/zh/use-cases/searxng) 或 [Xinference](/zh/use-cases/xinference) 指南。不同应用可保留的数据不同。
- **直接重装**：仅适用于没有用户数据需要迁移的应用。当前说明参见[共享应用](/zh/manual/olares/market/shared-apps#选项二-重新安装)。

## 从独立 Ollama 迁移到引擎基座

从 Olares 1.12.6 起，应用市场不再提供独立 Ollama 应用。已安装的应用仍可运行，但无法再从应用市场更新。

新部署请使用 **Ollama 引擎基座**：

1. 在 Ollama 引擎基座上部署模型。
2. 从模型控制台复制 Base URL。
3. 重新配置之前连接独立 Ollama 的客户端。

完整设置步骤参见[运行本地大模型](/zh/use-cases/llm-base-apps)。

## 查看其他升级注意事项

### AI 应用

部分在 1.12.6 前安装的 AI 应用可能无法在升级后启动。如果遇到该问题，请卸载旧版本，并从应用市场安装最新兼容版本。如果已在 1.12.6 RC 阶段重新安装，则无需再次处理。

卸载包含用户数据的应用前，先查看迁移指南，并保留指南中指定的数据。

### Sonarr, Radarr 和其他 *Arr 应用

Olares 1.12.6 对 *Arr 配置做出了两项更改：

- **连接**：*Arr 应用改用内部入口 URL 通信，不再使用提供商 URL。
- **路径**：*Arr 应用和下载客户端改用统一的挂载目录结构。

按照 [*Arr 应用升级说明](/zh/use-cases/arrs-upgrade)更新受影响的 URL 和路径。如果使用独立下载客户端，还需查看[下载客户端升级说明](/zh/use-cases/download-clients-upgrade)。

### Olares One 自动开机

**自动开机**开关位于**设置** > **我的 Olares** > **我的硬件**。启用后，连接电源或断电恢复时，Olares One 会自动启动。

该功能需要 Olares OS 1.12.6 或更高版本，以及 EC 1.03 或更高版本。条件不满足时，开关会保持禁用状态。可参阅[管理 BIOS 和 EC](/zh/one/update-firmware) 来检查或更新 EC 固件。
