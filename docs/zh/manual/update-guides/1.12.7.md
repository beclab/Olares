# 更新到 Olares 1.12.7 后需要做什么

Olares 1.12.7 调整了应用的模型连接方式。本次更新不影响已有的应用和数据。

更新完成后，请完成以下设置，开始使用新的 AI 功能。

:::warning 按步骤升级
如果你当前使用的是 Olares 1.12.5 或更早版本，需要先升级到 1.12.6，再升级到 1.12.7。具体影响和处理方式请参考[更新到 Olares 1.12.6 后需要做什么](./1.12.6.md)。
:::

## 安装 Router、Lares 和模型

从 1.12.7 开始，Olares 上的应用通过 Router 调用模型。Router 是管理模型和工具的 AI 网关。Lares 是 Olares 的官方 AI 助手，无需手动配置即可自动使用 Router 中配置的模型和工具。与其他智能体应用一样，Lares 内置了 Olares CLI 和 Agent Skills。

建议按以下顺序安装：

1. 打开**应用市场**，安装 **Router**。
2. 安装 **Lares**。
3. 安装一个本地模型。大多数设备可以从 **Qwen3.8-27B** 开始。

   :::info Olares One 用户：同时只运行一个请求
   Qwen3.8-27B 是稠密模型，智能体任务依赖长上下文窗口。Olares One 的显存为 24 GB，为了保证 100K 的上下文窗口和精度，建议同时只运行一个请求，等当前任务完成后再开始下一个任务。同时运行多个请求可能会变慢或卡住。
   :::

4. 打开 Lares，先让它做一个简单任务，例如检查本机配置，确认一切正常。

## 升级智能体应用

系统升级完成后，请从应用市场升级 Olares 上安装的智能体应用（如 Claude Code），确保它们在新版本上正常工作。升级应用时会一并更新内置的 Olares CLI 和 Agent Skills。

## 应用通过 Router 连接模型

AI 应用和第三方应用的教程已更新为 Router 连接方式。简单来说，应用的模型端点改为 Router 的 Base URL，模型名填 `default-chat`，不再直连模型后端。默认模型可以在 Router 中调整，无需重新配置应用。

如果你在 1.12.7 之前配置过应用，下次使用时请更新它的模型连接设置。
