# Lares

Lares 是 Olares 的官方 AI 助手，在 v1.12.7 中首次推出。你用自然语言说出一个目标，Lares 会在你的设备上规划并执行任务：检查系统状态、安装应用、整理文件等。从第一个请求到最终结果，全部在同一个对话中完成。

## 核心能力

无论是简短的日常指令，还是复杂的多步自动化，Lares 都能胜任。

**日常任务**

日常系统管理中，Lares 就是你设备的自然语言入口：

- **系统与应用管理**：查看设备状态、检查日志，或在 Market 中管理应用。
- **文件操作**：在 Olares Files 中读取、移动、压缩和整理文件。
- **应用控制**：操控已连接的应用，比如智能家居设备或媒体播放器。

**高级工作流**

Lares 是自主智能体，能力不限于单次指令。它能拆解复杂目标，串联多个工具，在系统中执行端到端的完整计划。

## Lares 的工作原理

- **与 Router 无缝集成**：Lares 自动接入你在 Router 中配置的 AI 模型和工具。它通过集群内应用身份完成认证，无需个人登录，也无需 API 密钥。
- **权限可控的执行**：Lares 通过 Olares CLI Agent Skills 代你执行任务，但权限范围由你掌控。你可以为它指定具体的权限级别，比如只读、写入或完全访问，精确界定它在系统上可以执行哪些操作。
- **一次一个任务**：本地 AI 模型通过时间片共享加速卡资源，一次只能处理一个请求。
    - **Lares 内的排队**：Lares 一次处理一个任务。任务运行期间，新请求会排队等待，当前任务结束后自动开始。
    - **同时运行多个智能体**：要同时运行 Lares 和其他智能体，请将它们连接到不同的模型。

## 开始使用

装好 Router 并连接模型后，打开 Lares，提出你的第一个问题：

```text
我刚接触 Olares，先帮我检查一下这台设备的配置。
```

:::tip 一次一个请求
Lares 一次处理一个请求。如果你在任务完成前又发了一条消息，它会排队等待，当前任务结束后立即处理。如果你同时要运行另一个智能体，请给它分配不同的模型。
:::
