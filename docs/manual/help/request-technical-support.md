# Get technical support

If you cannot resolve an issue using the troubleshooting guides, report what happened and include enough context for the Olares team to investigate. Collect full system logs only when they are needed, and share them privately.

## Describe the issue

Include:

- The shortest steps that reproduce the issue.
- The expected result and what happened instead.
- The complete error message and the time it occurred.
- Your Olares version, affected app version, and relevant hardware or operating system.
- Recent changes, such as an Olares update, app update, network change, or restart.

Remove passwords, recovery phrases, API keys, access tokens, and other secrets from descriptions and screenshots.

## Choose a contact channel

- Open a [GitHub Discussion](https://github.com/beclab/Olares/discussions/new?category=q-a) for general questions or assistance.
- Create a [GitHub Issue](https://github.com/beclab/Olares/issues/new) for a reproducible software bug.

Do not attach a complete system log archive to a public Discussion or Issue.

## Provide logs when requested

When the Olares team asks for logs, follow [Collect diagnostic information](../collect-diagnostic-information.md). Send the archive through the private channel provided to you or email [hi@olares.com](mailto:hi@olares.com), and include the related Discussion or Issue number if there is one.
