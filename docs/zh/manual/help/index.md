# 帮助与故障排查

当 Olares 的运行结果不符合预期时，请从本节开始。你可以按现象查找排障指南，或确认近期版本是否存在已记录的问题。

## 选择合适的入口

| 你的需求 | 从这里开始 |
|---|---|
| 根据错误或异常现象查找解决方案 | [排查 Olares 故障](./troubleshooting-guide.md) |
| 查看特定版本的问题及临时解决方法 | [已知问题](./known-issues.md) |

## 搜索文档

使用页面顶部的搜索框。优先搜索能描述现象的最短准确短语，例如错误信息、产品名称或操作：

- `Authentication failed, disk space is full`
- `LarePass 专用网络`
- `应用状态`
- `磁盘空间已满`

如果结果太多，可组合产品和现象，例如 `应用市场 缺少应用` 或 `Ollama 磁盘空间`。
