# 应用安装、更新期间或之后失败

当应用安装或更新失败、操作一直没有结束，或操作完成后应用无法启动时，请参考本文排查。

## 检查失败的操作

1. 打开**应用市场**，进入**我的 Olares**。
2. 点击右上角的**日志**。
3. 找到失败的安装或更新操作，记录发生时间、操作类型、应用版本和完整错误信息。
4. 重试前先下载操作日志。后续操作可能会覆盖界面中最有用的上下文。

## 根据错误选择下一步

| 错误或现象 | 处理方法 |
|---|---|
| CPU 或内存不足 | 停止暂时不用的应用，然后参考[内存不足或没有释放](./ts-free-memory.md)。 |
| 磁盘空间不足 | 参考[清理磁盘空间](../free-up-disk-space.md)，再重试操作。 |
| GPU 或显存分配失败 | 参考 [GPU 应用安装或恢复后处于暂停状态](./ts-vram-shortage.md)。 |
| 依赖应用缺失或已停止 | 查看应用详情页的**依赖**。先安装或恢复所需应用。集群成员可能需要管理员先安装共享依赖。 |
| 应用要求更高的 Olares 版本 | 先前往**设置** > **系统** > **更新**升级 Olares，再重试应用更新。 |
| 操作已经完成，但应用无法打开 | 前往**设置** > **应用**检查应用状态。如果应用已停止，只恢复一次，并记录启动窗口显示的提示。 |

## 检查是否曾在设置之外修改配置

应用更新可能会覆盖直接在控制面板或底层工作负载中修改的配置。这类修改不是 Olares 支持的持久配置方式。

如果应用需要环境变量或其他应用配置，请前往**设置** > **应用** > **[应用]**，并检查应用自身的设置。只重新填写你能够确认的配置值。不要在截图或公开问题报告中包含密钥。

持久化环境变量的可用方式详见[管理应用环境变量](../olares/settings/manage-app-env.md)。

## 安全重试

解决操作日志中显示的问题后：

1. 从应用市场重试一次安装或更新。
2. 等待操作完成后，再执行其他启停或更新操作。
3. 确认应用在**设置** > **应用**中显示为**运行中**，然后从启动台打开应用。

请勿为了强制重装而删除应用命名空间、Application 资源、Deployment 或共享服务。这些资源可能由 Olares 管理或被多个应用共用，删除后可能影响其他用户，或造成应用记录不一致。

## 应用仍然卡住

向支持人员提供以下信息：

- Olares 版本，以及操作前后的应用版本。
- 本次操作是首次安装、更新还是恢复应用。
- 应用市场和设置中显示的完整状态。
- 从应用市场下载的操作日志。
- 失败时间，以及此前刚进行过的配置更改。

如果需要更多系统信息，请参考[收集诊断信息](../collect-diagnostic-information.md)，并通过私密支持渠道共享日志压缩包。
