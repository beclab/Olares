# 角色与权限

Olares 通过三种内置角色控制集群、共享资源和团队成员的管理权限。分配角色或请求管理员执行操作前，可以在本页确认所需权限。

## 角色类型

- **超级管理员（Super Admin）**：首位激活 Olares 的用户。拥有完整的系统控制权限，可以创建或管理管理员与成员账户。
- **管理员（Admin）**：由超级管理员创建。可以管理系统和成员账户，但无法创建、管理或删除其他管理员。
- **成员（Member）**：由超级管理员或管理员创建的普通用户。可以使用个人资源和获准访问的共享资源，但不能执行集群级管理任务。

## 权限矩阵

| 权限 | 成员 | 管理员 | 超级管理员 |
|---|:---:|:---:|:---:|
| 使用系统应用 | ✅ | ✅ | ✅ |
| 通过 LarePass 专用网络访问 Olares | ✅ | ✅ | ✅ |
| 连接 Olares Space 账户 | ✅ | ✅ | ✅ |
| 自定义个人应用入口 | ✅ | ✅ | ✅ |
| 从应用市场安装普通应用 | ✅ | ✅ | ✅ |
| 访问已获权限的共享 Vault 项目 | ✅ | ✅ | ✅ |
| 在控制面板中查看基础系统状态 | ✅ | ✅ | ✅ |
| 管理 Vault 团队和共享 Vault | ❌ | ✅ | ✅ |
| 安装和管理共享应用 | ❌ | ✅ | ✅ |
| 监控和管理系统资源 | ❌ | ✅ | ✅ |
| 配置加速器使用模式 | ❌ | ✅ | ✅ |
| 更新 Olares | ❌ | ✅ | ✅ |
| 创建、编辑和删除成员 | ❌ | ✅ | ✅ |
| 创建、编辑和删除管理员 | ❌ | ❌ | ✅ |

添加用户、调整资源限制、重置成员密码或移除用户的方法，参见[创建并管理团队成员](manage-team.md)。
