# 使用 U 盘

Olares 会自动识别并挂载插入的 USB 存储设备。

- 设备插入后将自动挂载，无需命令行操作。
- 你可以在 Olares 网页端或 LarePass 中，点击**文件管理器** > **外部设备**直接访问。
- 直接拔出 USB 设备后，系统会自动完成卸载。
- 你也可以在 Olares 网页端手动移除设备。在**文件管理器**中右键点击该 USB 硬盘，选择**卸载**即可断开连接。
