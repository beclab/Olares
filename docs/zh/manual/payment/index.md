# Olares Payment

**Olares Payment 是 Olares 生态的稳定币收款服务。** 你用它收 USDC / USDT;买家用 MetaMask 等任意钱包付款;货款**在链上直接进你自己的钱包**——平台全程不托管资金。

## 为谁而做

- **应用开发者**——给自己的应用或内容开通付费
- **独立商户与创作者**——给自己的店铺、服务、数字作品收款
- **任何想用稳定币收款的人**——一个 LarePass 账号就够

## 为什么选择 Olares Payment

| 亮点 | 说明 |
|---|---|
| **收款直达自己的钱包** | 买家在链上直接转账到你的地址,平台不经手资金——没有资金池,没有提现环节。 |
| **一次扫码,立即收款** | LarePass 扫码登录即开通商户账户,7 条主流链的收款地址自动配好,就是你的 LarePass 钱包地址。 |
| **买家零门槛** | 买家不需要 Olares 账号,MetaMask、OKX 等任意浏览器钱包都能付。 |
| **稳定币结算** | USDC / USDT,覆盖 Optimism、Base、BNB Smart Chain、Ethereum、Arbitrum One、Polygon、Avalanche 七条链。 |

## 三步开始收款

1. **登录开通**——在浏览器打开 [https://www.olares.com/payment/dashboard](https://www.olares.com/payment/dashboard/),用 LarePass 扫码登录,账户与收款地址即刻就绪。
2. **分享或集成**——生成定额账单链接发给买家即可收款;在自己的网站或应用里收款则集成 API(见开发者文档)。
3. **买家付款,货款直达**——买家在收银台选币、连钱包、链上支付;确认后资金直接进你的钱包,后台实时可见。
