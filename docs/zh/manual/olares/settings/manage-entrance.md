# 管理应用入口

入口定义了用户访问 Olares 应用的方式。详情参见[入口](../../../developer/concepts/network.md#入口)概念。

每个入口包含两部分：

* **端点**：用于访问应用的 URL。要自定义端点（如设置自定义路由 ID 或域名），参见[自定义应用 URL](custom-app-domain.md)。
* **访问策略**：控制谁可以访问应用，以及访问时需要使用哪种认证方式。本节介绍访问策略。

## 了解认证级别和模式

访问策略用于控制谁可以访问应用，以及访问时需要使用哪种认证方式。

使用下表选择适合每个入口的认证级别：

| 认证级别 | 可用认证模式 | 访问行为 |
| --- | --- | --- |
| **公开** | 无 | 任何人无需登录即可打开应用。 |
| **私有** | 跟随系统、单因素、双因素 | 所有人访问前都必须完成认证。 |
| **内部** | 跟随系统、单因素、双因素 | 通过 LarePass VPN 的用户无需认证；其他访问均需认证。 |

* **认证级别**：入口的整体身份验证要求。

   * **公开**：任何人都可以访问，无需登录。
   * **私有**：需要用户登录才可访问。
   * **内部**：如果通过专用网络访问应用，则无需登录。

* **认证模式**：验证用户身份的方法。

   * **跟随系统**：继承**我的 Olares**页面中设置的系统身份验证规则。
   * **单因素**：仅需要 Olares 登录密码。
   * **双因素**：需要 Olares 密码以及二次验证码。
   * **无**：无需任何身份验证即可访问。

## 设置认证级别和模式

1. 前往**设置** > **应用**。
2. 点击目标应用。
3. 在**入口**下，点击目标入口。

   ![应用入口](/images/zh/manual/olares/app-entrance1.png#bordered){width=90%}

4. 在**访问策略**面板中，设置**认证级别**和**认证模式**。

   ![访问策略面板](/images/zh/manual/olares/app-entrance-access-policy-panel.png#bordered){width=70%}

5. 点击**提交**。

## 管理子策略

使用**正则表达式**可以为应用中的特定路径设置更细粒度的访问规则。

1. 在**访问策略**面板中，点击 <i class="material-symbols-outlined">chevron_forward</i> 打开**管理子策略**页面。
2. 点击**添加子策略**，然后在**受影响 URL** 中输入目标路径，并设置**认证模式**。
3. 点击**提交**。
