# Olares One 无法开机或没有画面

当 Olares One 看起来没有开机，或者状态灯已亮但连接的显示器仍然没有画面时，请参考本文排查。

## 判断故障现象

更改系统前，请先观察状态灯：

| 你看到的现象 | 说明 |
|---|---|
| 状态灯不亮，也没有风扇或其他启动迹象 | 设备可能没有正常供电。 |
| 状态灯为白色常亮 | Olares One 已通电，请继续检查显示与启动状态。 |
| LarePass 或浏览器可以访问 Olares，但显示器没有画面 | 系统正在运行，应重点检查显示器、电缆和输入源。 |

## 设备没有通电迹象

1. 确认电源线与 Olares One 和电源适配器连接牢固。
2. 将电源适配器直接连接到可用的墙上插座。如有条件，可用其他设备确认插座供电正常。
3. 断开非必要的 USB 设备和外接存储，然后按一次电源键。
4. 观察状态灯，并留意风扇或其他启动迹象。

如果设备仍然没有任何通电迹象，请停止操作并联系 Olares 支持。不要把拆机或更换内部组件作为通用排障步骤。

## 设备已通电但没有画面

1. 确认显示器已经开启，并选择了 Olares One 所连接的输入源。
2. 重新插拔显示电缆两端。如有条件，可更换电缆或显示器测试。
3. 断开非必要外设，只保留电源、显示器和有线键盘。
4. 重启 Olares One。出现徽标时，或刚按下电源键后，连续按 **Delete**，尝试进入 BIOS。

如果 BIOS 可以显示，说明 Olares One 能够输出画面，剩余问题可能来自操作系统启动，而不是供电或显示硬件。如果设备已连接路由器但无法访问 Olares，请参考[网络尚未准备好或 Olares 连接错误](/zh/manual/help/ts-network-not-ready.md)。

如果 BIOS 仍然没有显示，请检查键盘的 **Caps Lock** 指示灯是否响应，并记录结果。但除非 Olares 支持确认该操作适用于你的具体情况，否则不要盲目重置 BIOS、刷写固件、重装操作系统或拆除存储设备。

## 向支持人员提供的信息

请记录：

- 设备序列号。
- 状态灯颜色和变化方式。
- 是否能听到风扇或其他启动声音。
- 测试过的显示器、输入源和电缆。
- BIOS 是否显示，以及键盘是否响应。
- 问题发生前刚进行过的操作，例如重启、断电、更新或更换显示设备。

状态灯和显示器表现的照片或短视频，有助于区分供电、启动和显示问题。
