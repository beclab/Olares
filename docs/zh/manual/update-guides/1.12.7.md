# 更新到 Olares 1.12.7 后需要做什么

Olares 1.12.7 引入了 Router 和 Lares，并调整了应用的模型连接方式。本次更新不影响已有的应用和数据。

更新完成后，请完成以下设置，开始使用新的 AI 功能。

## 安装 Router、Lares 和模型

Olares 上的应用现在通过 Router 调用模型。建议按以下顺序安装：

1. 打开**应用市场**，安装 **Router**。
2. 安装 Olares 的第一方智能体 **Lares**。
3. 安装一个本地模型。大多数设备可以从 **Qwen3.8-27B** 开始。

   :::info Lares 一次处理一个任务
   Lares 执行任务期间，新的请求会排队等待，当前任务完成后自动开始。本地模型通过时间分片共享加速器，运行中的任务不会阻塞其他应用。如果需要 Lares 和其他智能体同时工作，请让它们连接不同的模型。
   :::

## 应用通过 Router 连接模型

AI 应用和第三方应用的教程已更新为 Router 连接方式。简单来说，应用的模型端点改为 Router 的 Base URL，模型名填 `default-chat`，不再直连模型后端。默认模型可以在 Router 中调整，无需重新配置应用。

如果你在 1.12.7 之前配置过应用，下次使用时请更新它的模型连接设置。
