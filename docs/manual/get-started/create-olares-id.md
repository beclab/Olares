# Create an Olares ID

Your Olares ID belongs to you and is used to activate and access Olares.

An Olares ID consists of a local name and a domain. For example, in `alice123@olares.com`:
- `alice123`: Local name
- `olares.com`: Domain name

:::tip Learn how Olares ID works
For details about its structure and technical design, see [Olares ID](../../developer/concepts/olares-id.md).
:::

## Set up your Olares ID

1. [Install LarePass](/manual/larepass/) on your phone and open it.
2. Tap **Create an account**, choose an ID, and tap **Continue**.

::: tip
For advanced use cases, such as using a custom domain or setting up identities for a team, see [Set up a custom-domain Olares ID](../best-practices/set-custom-domain.md).
:::
