# 使用 Qwen Image 2.1 生成和编辑图片

Qwen Image 2.1 是 Olares 维护的图片创作应用，通过本地运行的 Qwen Image 2.1 模型，根据文字生成图片或修改已有图片。你可以通过可视化界面结合参考图创作、修改局部区域、扩展画面和去除背景。

提示词的 AI 润色功能通过 Router 调用文本模型，帮助你完善画面描述。

## 学习目标

- 安装应用并下载图片模型。
- 配置用于 AI 润色的文本模型。
- 生成商品图，调整颜色、构图和背景。
- 查找、复用和下载创作结果。

## 前提条件

- Olares 1.12.8 或更高版本，以及用于安装应用和配置模型的管理员账号。
- 应用支持的 NVIDIA GPU。安装包申请 22 GiB 显存和 32 GiB 系统内存。
- 用于存放应用、生成图片和模型权重的磁盘空间。默认 INT8 权重的下载量约为 25 GB。

## 安装应用并准备图片模型

1. 打开应用市场，搜索“Qwen Image 2.1”。
2. 点击**获取**，然后点击**安装**。出现环境变量配置时，本教程使用 **PRECISION** 的默认值 `int8`。

   | 选项 | 下载量 | 用途 |
   | --- | --- | --- |
   | INT8 | 约 25 GB | 默认选项，使用官方发布的权重。 |
   | NVFP4 | 约 27 GB | 使用第三方转换的权重。 |

   **STUDIO_LLM_BASE_URL** 和 **STUDIO_LLM_API_KEY** 留空，**STUDIO_LLM_MODEL** 保持为 `default-chat`。这套默认配置会将提示词润色连接到当前 Olares 的 Router。

3. 确认配置，等待应用安装完成。
4. 从启动台打开 Qwen Image 2.1。首次启动会下载所选的图片模型，等待下载页面结束并进入创作界面。
5. 打开**设置** > **模型**，确认 INT8 权重显示**已安装**。点击**打开模型控制台**可查看各文件的下载进度和校验信息。模型下载完成、生成服务就绪后，即可提交第一个任务。

下面的示例使用 INT8。后续可在**设置**中下载另一种精度的权重，并在生成时选择已安装的精度。

## 配置用于 AI 润色的文本模型

你可以直接输入自己的提示词来生成和编辑图片，也可以连接文本模型，通过 **AI 润色**完善描述。

本教程使用 Qwen3.8-27B (llama.cpp)。它在本地运行，也能接收参考图片。

1. 在 Olares 上准备好文本模型。如果尚未安装，在应用市场搜索“Qwen3.8-27B (llama.cpp)”，点击**获取**和**安装**并完成安装。打开它的模型控制台，等待 **Model** 显示 **Ready**，**Engine** 显示 **Running**。

   如需其他模型，可安装对应的模型应用，或参考[通过引擎基座应用运行本地大模型](llm-base-apps.md)。

2. 从启动台打开 Router，在 **Default models** 页面为 `default-chat` 选择该文本模型。
3. 返回 Qwen Image 2.1，打开**设置**。在 **AI 优化（AI optimize）**区域点击**刷新**，重新获取 Router 中的文本模型列表。
4. 在**对话模型**中，保留 **Router 默认（default-chat）**以跟随 Router 的默认设置，或从列表中选择具体模型。确认状态显示**可用**。

   标有**能看图**的模型会结合参考图片润色提示词。纯文本模型只接收文字。选择具体模型后，应用会使用该模型，不随 Router 默认模型的切换而改变。

使用默认环境配置时，应用会自动连接 Router。

## 生成和编辑图片

下面以咖啡杯商品图为例，演示从生成图片到调整用途的过程。你可以替换为自己的商品和修改需求。

**应用**页面和输入区顶部的菜单提供**生成图片**、**局部重绘**、**扩图**和**去背景**入口。也可以打开生成结果，直接使用图片下方的操作按钮。

### 根据文字生成图片

1. 选择**生成图片**。仅根据文字创作新图时，先通过缩略图上的移除按钮清除已有参考图。
2. 在**提示词**中描述画面。例如：

   ```text
   一张简洁的商品摄影图：哑光青绿色陶瓷咖啡杯放在暖象牙色桌面上，清晨的柔和窗光从左侧照入，杯子旁散落几颗咖啡豆。极简构图，不添加文字或标志。
   ```

3. 如需润色，点击 **AI 润色**旁的箭头，选择**润色并译成英文**、**润色，保留原语言**或**只翻译成英文**，然后点击 **AI 润色**。阅读改写结果，生成前调整不符合预期的细节。
4. 将比例设为 **1:1**，张数设为 **1**。展开**高级设置**，使用 **1K** 清晰度、**INT8** 精度和随机种子。

   | 设置 | 如何选择 |
   | --- | --- |
   | **比例** | 方形商品图可用 1:1，横幅可用 16:9，竖版构图可用 9:16。 |
   | **张数** | 一次生成 1–4 张候选图。调整描述时先生成一张即可。 |
   | **清晰度** | 初稿使用 1K。需要生成更高分辨率的版本时，选择 2K。 |
   | **速度** | 在支持的图片编辑路径中可选。文字生图和参考生成只有一种速度。 |
   | **种子** | 随机种子适合生成新变化。需要用同一个起始种子比较提示词调整时，可锁定种子。 |

5. 点击**生成**。任务会出现在**生图**页面并显示进度。点击**查看队列**可了解正在生成和等待中的任务。
6. 打开完成的图片查看效果。**详情**中可以查看提示词、参考图和生成参数。

### 用文字修改已有图片

用文字说明修改内容，可以在保留构图的基础上调整图片。例如，为同一款咖啡杯制作另一种颜色的商品图。

1. 打开生成的咖啡杯图片，点击**编辑**。它会成为第一张参考图，比例切换为**跟随图1**。
2. 描述要修改和保留的内容：

   ```text
   只把咖啡杯改成陶土橙色。保持杯子的形状、把手、位置，以及咖啡豆、桌面、光线和构图不变。
   ```

3. 保持**比例**为**跟随图1**，点击**生成**。
4. 打开结果，启用**和原图对比**，移动分隔线查看修改前后的差异。

![对比青绿色原图与改为橙色后的咖啡杯](/images/manual/use-cases/qwen-image-2.1-edit-compare.jpg#bordered)

使用自己的照片时，选择**生成图片**，通过**添加图片**上传或从素材库选择图片，并将比例设为**跟随图1**。第一张参考图就是被编辑的图片。

### 结合参考图创作新画面

参考生成会将图片中的元素用于新的构图。在输入区添加参考图后，为新图片选择输出比例。

1. 选择**生成图片**并添加参考图，最多可添加 10 张，也可以从**素材库**中选择已有图片。
2. 打开参考图缩略图，设置**图片用途**，例如**商品**、**人物**、**风格**或**场景**。咖啡杯照片可选**商品**，说明需要保留的是它的外观。
3. 在**提示词**中输入 `@`，从列表中选择图片，在描述其用途的位置插入引用。例如，分别引用咖啡杯图片和咖啡馆图片：

   ```text
   将[商品参考图]中的咖啡杯放在[咖啡馆参考图]的桌子上。保持杯子的颜色、形状和把手设计，使用温暖的晨光，画面右侧留白以便后续添加标题。不要生成文字。
   ```

   将方括号中的描述替换为通过 `@` 插入的图片引用。

4. 选择输出比例，例如使用 **16:9** 创建横向构图。
5. 选择清晰度和张数，点击**生成**。使用结果前，检查商品的形状与细节是否符合预期。

可以拖动参考图缩略图调整顺序，也可以直接从参考图区移除图片。对带图片引用的提示词使用 AI 润色后，检查改写结果是否仍引用了正确的图片。

### 局部重绘图片

只想修改画面的一部分时，使用**局部重绘**。例如，移除咖啡杯旁的咖啡豆。

1. 打开橙色咖啡杯图片，点击**局部重绘**。
2. 点击**涂抹遮罩**，涂抹咖啡豆及其附近阴影。可调整**笔刷大小**，使用**橡皮**修整选区，也可以通过**撤销**或**清空**重新处理。
3. 点击**完成**。输入区会显示**修改遮罩**和**移除遮罩**按钮。
4. 在**想改成什么？**下输入：

   ```text
   移除咖啡豆，用相同的暖象牙色桌面纹理填补对应区域。保持咖啡杯和照片其他部分不变。
   ```

5. 点击**应用修改**。生成后与原图对比，检查选区边缘的衔接。

![涂抹咖啡豆所在区域，准备应用局部修改](/images/manual/use-cases/qwen-image-2.1-inpaint-mask.jpg#bordered)

模型会参考整张图，最终结果保留遮罩外的原图。选区需要覆盖希望修改的内容，并为周围过渡留出空间。

### 扩展图片画幅

使用**扩图**可以在已有图片周围补充内容。例如，在咖啡杯右侧留出放置标题的空间。

1. 打开图片，点击**扩图**。
2. 在画布编辑器的**比例**中选择 **16:9**。也可以选择**保持比例**，通过**扩展幅度**增加原比例画布的大小。
3. 在画布内拖动原图，控制新增内容的位置。需要向右扩展时，将原图向左移动。检查预览和显示的尺寸。
4. 点击编辑器中的**扩图**，提交任务。
5. 打开结果，检查原图与新增区域的交界。纯色背景可能出现接缝或纹理变化，需要时调整扩展范围后重新生成。

从**应用**页面进入**扩图**时，先添加**源图片**，再点击**调整位置和范围**打开同一个画布编辑器。

### 去除图片背景

1. 打开图片，点击**去背景**。
2. 确认**源图片**是需要处理的图片，然后点击输入区中的**去背景**。
3. 打开生成结果。棋盘格表示透明区域，注意检查细小边缘和杯把内部。
4. 点击**下载**，保存带透明背景的 PNG。

![去背景后保留的咖啡杯和咖啡豆](/images/manual/use-cases/qwen-image-2.1-remove-background.jpg#bordered)

如果需要单独的咖啡杯素材，先使用**局部重绘**移除咖啡豆，再去除背景。

### 基于结果继续创作

根据希望沿用的内容选择操作：

| 操作 | 用途 |
| --- | --- |
| **复用参数** | 将提示词和生成设置带回输入区，调整后再提交任务。 |
| **生成变体** | 沿用提示词和设置，使用新的随机种子生成其他候选图。 |
| **作为参考** | 将结果添加为下一次创作的输入。 |
| **编辑** | 对这张图片做文字描述的修改。 |

对于上传的照片，可以使用**编辑**修改内容，或通过**作为参考**将其用于新的构图。

## 查找和下载作品

**生图**页面按生成任务展示结果。通过**搜索提示词**查找描述，或用**筛选**按类型和日期缩小范围。**布局**用于切换结果展示方式。

**素材库**分为**生成**、**上传**和**收藏**。点击图片上的爱心图标可加入**收藏**，也可以通过**搜索名称**查找素材。

下载单张图片时，打开它并点击**下载**。下载多张图片时，勾选图片的选择框，再点击选择工具栏中的**下载**，应用会将所选图片打包为 ZIP 文件。下载的图片保留输出时的尺寸和文件格式。

## 常见问题

### 打开应用后为什么无法生成图片？

打开**设置** > **模型**和模型控制台，查看下载与启动进度。权重显示**已安装**、生成服务就绪后，即可提交任务。

### 显示“Router 里没有对话模型”时如何处理？

确认文本模型在 Router 中可用，再到应用**设置**的 **AI 优化**区域点击**刷新**。配置润色功能期间，可以直接输入自己的提示词生成图片。

### AI 润色提示图片引用丢失时如何处理？

应用会保留原提示词。可以继续使用原文，或简化后再次润色。生成前，检查改写后的提示词是否引用了正确的图片。

### 编辑图片时如何保留原有构图？

将需要修改的图片放在参考图区第一位，并将**比例**设为**跟随图1**。修改指定区域时，使用**局部重绘**并涂抹对应区域的遮罩。

### 生成时显存不足怎么办？

先查看失败任务的错误信息，再尝试使用 **1K** 清晰度并减少参考图数量。
