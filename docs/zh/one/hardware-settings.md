# 查看设备状态与硬件设置

通过**设置**中的**集群概览**，你可以查看 Olares One 的设备状态和硬件详情，并调整工作模式、自动开机等设置。

你的 Olares One 会作为一个节点显示在集群中。

## 查看集群状态

打开**设置**，点击左上角的头像，然后点击**集群概览**。

查看集群的健康状态、连接状态和运行状态，以及 Olares OS 版本和节点数量。

![集群概览](/images/zh/manual/olares/cluster-overview-1.12.7.png#bordered)

## 查看设备详情

在**节点**列表中，点击你的 Olares One，打开节点详情页面。

页面会显示节点的健康状态、连接状态和运行阶段，以及 CPU、GPU、内存和磁盘容量。你还可以查看 Olaresd 版本和节点信息的最近观测时间。

![设备详情](/images/zh/manual/olares/device-detail-1.12.7.png#bordered)

## 切换工作模式

在节点详情页面的**节点设置**中，点击**工作模式**并选择性能档位：

- **静音模式**：限制 CPU/GPU 功耗，满足日常负载并保持安静。
- **性能模式**：释放 CPU/GPU 最大性能，适合 AI 推理、游戏等高负载场景。

## 限制 CPU 频率

在节点详情页面的**节点设置**中，找到**限制 CPU 频率**。

开启后，将 CPU 频率上限从 5.4 GHz 降至 5.0 GHz。关闭后恢复原有最高频率。

## 设置自动开机

在节点详情页面的**节点设置**中，开启**自动开机**。设备在接通电源或停电后恢复供电时会自动开机。

:::info
需要 Olares OS 1.12.6 或更高版本，以及 EC 固件 1.03 或更高版本。如果任一条件未满足，开关会显示但无法操作。

如需查看当前 EC 固件版本或升级 EC 固件，可参考[管理 BIOS 和 EC](update-firmware.md)。
:::

## 重置 SSH 密码

如需使用自定义 SSH 密码，而不是激活时自动生成的密码，可在设置中重置：

1. 在节点详情页面的**节点设置**中，点击**重置 SSH 密码**。
2. 输入符合强度要求的新 SSH 密码，然后点击**重置**。

   ![重置 SSH 密码对话框](/images/zh/one/ssh-reset-password-in-settings-1.12.7.png#bordered)

3. 打开 LarePass，扫描屏幕上显示的二维码。
4. 在 LarePass 中点击**确认**完成操作。新密码会自动保存到 Vault。

## 重启或关闭设备

重启或关机前，请先保存工作。这些操作会中断正在运行的应用和任务。

- 如需重启你的 Olares One，在节点详情页面点击**重启节点**。
- 如需重启所有节点，返回**集群概览**，点击**重启集群**。
- 如需关闭所有节点，返回**集群概览**，点击**关闭集群**。

如果集群中只有一台 Olares One，**重启节点**和**重启集群**都会重启这台设备。
