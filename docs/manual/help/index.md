# Help and troubleshooting

Use this section when Olares does not behave as expected. Start with the symptom-based troubleshooting index, or check whether a recent release has a documented issue.

## Find the right help

| What you need | Start here |
|---|---|
| Match an error or unexpected behavior to a solution | [Troubleshoot Olares](./troubleshooting-guide.md) |
| Check a release-specific problem and its workaround | [Known issues](./known-issues.md) |

## Search the docs

Use the search box at the top of the page. Search for the shortest exact phrase that describes the symptom, such as an error message, product name, or action:

- `Authentication failed, disk space is full`
- `LarePass VPN`
- `app status`
- `disk space is full`

If the first search is too broad, combine the product and symptom, for example `Market missing apps` or `Ollama disk space`.
