# 管理公共目录和外部存储的访问权限

在文件管理器中，你可以指定哪些成员能查看或编辑公共目录和外部存储。

本文仅介绍公共目录和外部设备的权限设置。如需将首页或同步目录中的文件夹分享给其他成员，请参阅[分享文件](share-files.md)。

:::warning 前置条件
访问权限设置需要 Olares 1.12.8 或更高版本。请以超级管理员或有权管理目标文件夹的管理员身份登录。成员不能修改这些设置。为外部存储分配权限前，请先完成挂载。
:::

## 可以设置哪些文件夹

权限适用于所选文件夹及其中的所有文件和子文件夹，不能为各个子文件夹单独设置权限。这些设置控制成员通过文件管理器访问文件，不会修改 NAS 上的权限。

| 位置 | 可以设置权限的文件夹 | 示例 |
| --- | --- | --- |
| <nobr>**应用** > **公共**</nobr> | 公共目录下的一级文件夹 | `Common/huggingface` |
| <nobr>**存储** > **外部设备**</nobr> | 外部设备下的一级挂载目录：SMB 共享、NFS 共享、U 盘或本地磁盘。<br><br>**注意：** `ai` 系统文件夹对成员只读，不支持权限设置。 | `External/ProjectNAS` |

## 默认权限与管理范围

公共目录中的一级文件夹和外部设备的挂载目录采用以下默认规则。

| Olares 角色 | 默认权限 | 可以为谁设置权限 |
| --- | --- | --- |
| 超级管理员（Owner） | 完整管理权限 | 管理员和成员 |
| 管理员 | 完整管理权限，但超级管理员可以限制其访问 | 成员，但该管理员须仍有此文件夹的管理权限 |
| 成员 | 无权限 | 不能修改文件夹访问权限 |

有关 Olares 角色的说明，请参阅[管理多用户](../settings/manage-team.md)。

## 允许成员访问文件夹

1. 使用超级管理员或有权管理该文件夹的管理员账号登录 Olares，然后打开**文件管理器**。
2. 进入**应用** > **公共**，或**存储** > **外部设备**。
3. 右键点击一级文件夹或挂载目录，选择**权限设置**。

   ![公共目录文件夹右键菜单中的权限设置](/images/manual/olares/files-access-settings.png#bordered)

4. 找到需要授权的成员，选择权限：

   ![权限设置对话框](/images/manual/olares/files-access-settings-dialog.png#bordered)

   | 权限 | 成员可以执行的操作 |
   | --- | --- |
   | <nobr>**无权限**</nobr> | 无法在列表中看到该文件夹，也不能通过文件管理器访问其中的内容。 |
   | <nobr>**可查看**</nobr> | 浏览、预览和下载文件，不能添加、修改或删除内容。 |
   | <nobr>**可编辑**</nobr> | 查看文件，在文件夹内新建文件夹、上传文件，以及修改或删除内容。<br><br>**注意：** 拥有此权限的成员不能修改访问权限、从挂载目录创建 SMB 分享，或连接、卸载存储。也不能重命名、移动或删除公共目录的一级文件夹或挂载目录本身。 |
   | <nobr>**默认（无权限）**</nobr> | 恢复成员的默认权限：**无权限**。 |

5. 点击**确认**。
6. 请该成员刷新文件管理器并打开文件夹，确认能浏览其中的内容。若权限为**可查看**，该成员应无法上传或删除文件。

## 修改或撤销访问权限

1. 右键点击同一个文件夹，选择**权限设置**。
2. 修改用户的权限。如果要撤销成员的访问权限，选择**无权限**。
3. 点击**确认**。
4. 请该成员刷新文件管理器，检查新的权限是否生效。

撤销访问权限不会删除文件夹或其中的内容，也不会删除成员此前已经下载的副本。

:::info 默认权限取决于用户角色
管理员的默认权限是**管理**。超级管理员如需限制管理员的访问，请选择**可查看**或**无权限**等选项，而不是**默认**。
:::

## 常见问题

### 目录访问权限、内部分享和 SMB 分享有什么区别，什么时候用哪个？

根据文件夹所在的位置，以及对方访问文件的方式来选择：

- **目录访问权限**：让 Olares 成员通过文件管理器查看或编辑公共目录的一级文件夹或外部设备的挂载目录。使用文件夹的**权限设置**，例如只允许指定成员访问已挂载的 NAS 文件夹。
- **内部分享**：将首页或同步目录中的文件夹分享给其他 Olares 成员。需要邀请成员访问这两个位置中的文件夹时，使用此功能。公共目录和外部设备不支持内部分享。
- **SMB 分享**：让电脑通过局域网中的 SMB 协议访问首页或外部设备中的文件夹，例如在 Windows 文件资源管理器或 macOS 访达中访问。需要身份验证时，使用专用 SMB 账号，该账号与 Olares 成员账号相互独立。

创建 SMB 分享是让其他电脑访问 Olares 提供的文件夹。[挂载 SMB 共享](mount-SMB.md)则是将 NAS 或服务器上的文件夹接入 Olares。分享操作步骤请参阅[分享文件](share-files.md)。

### 为什么成员无法访问或编辑文件夹？

成员不能自行修改这些设置。如果成员反馈问题，请以超级管理员或管理员身份登录，并检查以下各项：

| 问题 | 检查方法 |
| --- | --- |
| 成员看不到文件夹，或看到“没有你可以访问的文件夹” | 检查该成员在一级文件夹或挂载目录上的权限。 |
| 成员能查看，但无法上传或编辑 | 检查该成员的权限是否为**可查看**。对于 NAS 存储，还需确认 NAS 端允许写入该共享目录。 |
| 找不到或无法使用**权限设置** | 确认选中的是公共目录的一级文件夹或外部设备的挂载目录，且当前账号有权管理该文件夹。 |
| 升级或更换存储后无法访问 | 确认挂载的是预期存储。检查该成员的访问权限设置，必要时重新授权。 |
