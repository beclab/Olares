# 将资源转存到 Olares

使用 LarePass 的转存功能，可以将网络资源直接保存到 Olares。添加链接或 Torrent 种子文件并选择保存位置后，Olares 会在后台处理转存任务。此功能仅支持 LarePass 桌面端。

需要将 Olares 中已有的文件下载到电脑时，可参阅[下载文件](manage-files.md#下载文件)。

:::warning 下载前请确认内容权限
请确保拥有下载相关内容的权限，例如自有内容、公有领域内容，或已获得下载授权的内容。下载时需自行负责遵守适用的版权法律及来源网站的服务条款。
:::

## 创建转存任务

:::info 下载音视频资源
如需从支持的媒体网站下载音视频，需要先安装 `yt-dlp` 组件。在 LarePass 中，前往**设置** > **下载器**，并在 **yt-dlp** 下方点击**前往 Olares 应用市场安装**。

下载种子文件、Hugging Face 模型以及常规链接无需此操作。
:::

1. 打开 LarePass 桌面端。
2. 进入**传输** > **转存**，然后点击**保存到 Olares**。
3. 在**新建任务**窗口，选择一种方式添加资源：
   - 粘贴 HTTP、HTTPS、磁力链接或 Hugging Face 链接。
   - 点击上传区域选择 `.torrent` 种子文件，或将文件拖入上传区域。
4. 粘贴链接或上传 Torrent 种子文件后，LarePass 会自动解析并进入任务详情页。检查识别到的资源和选中的文件是否正确。
5. 在**保存到**中选择资源在 Olares 中的保存位置。
6. 点击**下载**创建任务。

任务会显示在**传输** > **转存**中，可随时查看进度。

## 支持的资源来源

| 来源 | 添加内容 |
|------|----------|
| Torrent | `.torrent` 种子文件或磁力链接 |
| 网络链接 | HTTP 或 HTTPS 文件直链 |
| Hugging Face | 公开模型或仓库地址 |
| 音频或视频 | 受支持媒体网站的 URL；需安装 `yt-dlp` |

## 管理转存任务

进入**传输** > **转存**，选择对应页签：

- **正在转存**：暂停、继续或取消任务。
- **已完成**：查看任务详情、打开文件所在文件夹或删除任务。对于 Torrent 任务，还可以停止或恢复做种。

## 注意事项

- 链接必须完整、有效且可公开访问。转存不受支持的网站 URL 时，下载结果可能是 HTML 文件。如果可以获取文件直链，可改用直链。
- Torrent 下载依赖可用节点。如果任务没有进度，可稍后再查看，或更换其他资源来源。
