# 使用 MiniMax H3 生成有声视频

MiniMax H3 是 Olares 维护的视频创作应用，通过本地运行的 MiniMax H3 模型同时生成视频和声音。你可以从一段文字描述开始，让静态图片动起来，或用参考素材引导新片段。

AI 提示词优化通过 Router 连接的文本模型，在生成视频前完善和组织你的描述。

## 学习目标

- 安装应用并确认视频模型就绪。
- 用 AI 优化完善文本提示词，并用它生成视频。
- 让图片动起来，从视频的最后一帧继续创作。
- 用参考素材引导新视频。
- 查找和下载视频。

## 前提条件

- Olares 1.12.8 或更高版本，以及用于安装的管理员账号。
- 应用支持的 NVIDIA GPU。安装包申请 22 GiB 显存和 32 GiB 系统内存。
- 用于存放应用、生成视频和约 65 GB 模型文件的空间。共享模型存储中已有的模型可以直接复用。

## 安装 MiniMax H3 并准备模型

1. 打开应用市场，搜索“MiniMax H3”。
2. 点击**获取**，然后点击**安装**，等待安装完成。
3. 从启动台打开 MiniMax H3。首次启动时应用会准备视频模型，等待进入创作界面。
4. 在**设置**中点击**打开模型控制台**。等待页面显示 **Ready**，生成引擎 ComfyUI 显示 **up**。

::: tip 首次生成耗时更长
首次生成时模型需要加载到内存，可能耗时更长。可以在**结果**中查看进度。
:::

## 配置用于 AI 优化的文本模型

你可以直接用自己的提示词生成视频。如需 **AI optimize** 帮你组织和完善描述，通过 Router 连接一个文本模型。本教程使用 Qwen3.8-27B (llama.cpp)，一个在本地运行的文本模型。

1. 在应用市场安装“Qwen3.8-27B (llama.cpp)”。安装完成后，打开它的模型控制台，等待 **Model** 显示 **Ready**、**Engine** 显示 **Running**。

   如需其他模型，可安装对应的模型应用，或参考[通过引擎基座应用运行本地大模型](llm-base-apps.md)。
2. 从启动台打开 Router，进入 **Default models**，为 `default-chat` 选择 Qwen3.8-27B 模型。等待该行显示 **Callable**。
3. 在 MiniMax H3 中进入**设置** > **AI optimize**，点击**刷新**，重新加载 Router 中的文本模型。
4. 在**对话模型**中，保留 **Router 默认（default-chat）**以跟随 Router 的默认设置，或从列表中选择具体模型。确认状态显示**可用**。

   标有 **sees images** 的模型会结合参考图片改写提示词。纯文本模型只根据文字优化。选择具体模型后，该选择独立于 Router 的默认模型。

## 根据文字生成视频

使用 **Text** 仅通过描述开始创作。本例生成一段五秒的时尚镜头：象牙色套装、飘动的橙色丝绸和阳光下的砂岩庭院。后续小节会复用它的帧来续拍并创作新场景。你可以替换为自己的主体、场景和动作。

1. 进入 **Create**，选择 **Text**。
2. 在**提示词**中描述主体、动作、镜头、光线和声音。例如：

   ```text
   一段电影感的高端时尚大片，一镜到底。一位深色短卷发的成年女性站在阳光下的砂岩庭院中，佩戴小巧的金色耳环，身穿象牙色丝绸长裙。她身后，一条长长的半透明焦橙色丝绸缎带随风扬起，划出宽大优雅的波浪，阳光穿过时泛着琥珀色光泽。

   腰部以上中景人像，面部清晰可见，主体位于画面右侧三分之一处，飘动的织物铺满左侧。她缓缓侧脸迎向温暖的阳光，表情平静。镜头缓慢而轻微地推近。

   浅色的砂岩拱廊，澄净的粉蓝色天空，温暖的傍晚逆光，面部有柔和的反射光，真实的皮肤与细腻的织物纹理，克制的象牙色、陶土色与金色调，浅景深，35mm 胶片摄影。织物始终位于人物身后，不遮挡面部。

   声音：轻柔的微风和细腻的丝绸摩擦声。无对白，无音乐，无文字，无标志。
   ```

3. 可选地，点击 **AI 优化**完善和组织描述。生成前检查改写后的提示词，调整不需要的细节。
4. 可选地，如需优化但不翻译，或只翻译，点击 **AI 优化**旁的箭头，选择**优化，保留原语言**或**只翻译成英文**。
5. 设置基本生成选项：

   | 设置项 | <nobr>本示例</nobr> | 如何选择 |
   | --- | --- | --- |
   | **时长** | **5 s** | 先用短镜头调整动作。可以输入精确时长或使用预设。 |
   | **比例** | **16:9** | 宽幅构图适合主体和飘动的织物。 |
   | **清晰度** | **720p** | 需要更小的预览时选择 **480p**。 |
   | **视频数** | **×1** | 调整创意阶段一次生成一段。 |

6. 可选地，展开**高级设置**调整生成速度或种子。本示例保持默认即可：

   | 设置项 | <nobr>本示例</nobr> | 如何选择 |
   | --- | --- | --- |
   | **速度** | **Quality priority** | MiniMax H3 提供两种速度设置：<ul><li>**Quality priority**：三种输入模式均使用 20 个生成步数。</li><li>**Fast**：步数更少、出片更快，**Text** 和 **Frames** 为 8 步，**References** 为 4 步。</li></ul> |
   | **种子** | **Random** | 首次生成保持默认。 |

7. 点击**生成**，等待任务完成。
8. 打开结果，确认面部、织物、镜头运动和声音符合预期，再使用或继续创作。

   ![预览生成的时尚视频，以及播放、抓帧和续拍控制](/images/manual/use-cases/minimax-h3-text-result.jpg#bordered)

9. 可选地，点击**复用**再做一个版本。提示词和设置会回到输入区，调整后再次点击**生成**。

## 使用 Frames 让图片动起来

使用 **Frames** 让照片或插画动起来，也可以用已生成视频中的一帧。起始帧决定画面开端，可选的结束帧引导视频的结束位置。

1. 进入 **Create**，选择 **Frames**。
2. 通过以下来源之一添加必需的起始帧：

   - 图片：点击**起始帧**，上传图片或从素材库选择。
   - 已生成的视频：打开视频并暂停在想要的时刻，用**上一帧**和**下一帧**微调，然后选择**抓取帧** > **用作首帧**。

3. 可选地，添加结束帧。使用已生成视频中的帧时，选择**抓取帧** > **用作尾帧**。结束帧的主体和构图要与起始帧兼容。
4. 在**提示词**中描述主体和镜头如何运动、哪些内容保持不变，例如人物外观、服装和光线。
5. 选择时长和清晰度，点击**生成**。**比例**跟随起始帧。
6. 等待任务完成，打开结果播放。

### 从最后一帧继续

使用**继续**可以把一段视频的最后一帧加载为下一段的起始帧。本例延续文字小节生成的庭院视频。

1. 打开生成的视频，点击播放器下方的**继续**。应用会切换到 **Frames**，并把该视频的最后一帧添加为**起始帧**。
2. 将提示词替换为接下来要发生的内容。例如：

   ```text
   从这一帧继续，保持一镜到底的时尚大片风格。保持同一位女性、深色短卷发、金色耳环、象牙色丝绸套装和橙色丝巾不变。镜头缓慢拉远，展现更多阳光下的砂岩拱廊。她轻轻将目光转向庭院，半透明的橙色丝绸随风向左侧飘动。保持温暖的金色光线和自然的皮肤质感。声音：柔和的风声和丝绸摩擦声。无对白，无音乐，无文字。
   ```

3. 保持**结束帧（可选）**为空，让续拍开放式结束。**比例**跟随首帧。
4. 将**时长**设为 **5 s**，**清晰度**设为 **720p**。如需更快的动作预览，在**高级设置** > **速度**中选择 **Fast**，然后点击**生成**。
5. 播放新结果，比较它的开头与上一段的结尾。续拍是一段独立的视频，可以下载后在视频编辑器中与第一段拼接。

   ![以庭院视频的最后一帧作为起始帧续拍](/images/manual/use-cases/minimax-h3-frames-result.jpg#bordered)

## 使用 References 生成视频

使用 **References** 将主体或视觉风格带入新场景。本例用庭院视频中的一帧引导海边露台上的新镜头。

::: tip 参考素材限制与多输入
参考区最多接受五张图片、一个视频和一段音频，单个文件最大 512 MB。参考视频和音频的时长须为 2–15 秒。点击**添加媒体**旁的**文件格式**可查看支持的格式。

组合多个输入时，在描述其用途的位置分别提及，例如用人物图片确定外观、用视频提供动作。至少需要一个图片或视频输入，仅有音频无法进行 **References** 生成。
:::

1. 打开文字小节的庭院视频，暂停在人物清晰的画面，选择**抓取帧** > **仅存入素材库**。
2. 选择 **References**。点击**添加媒体** > **从素材库**，选中保存的帧，点击**选择**。使用自己的素材时改用**上传文件**。
3. 在**提示词**中粘贴以下描述：

   ```text
   以@[人物参考图]作为女性、深色短卷发、金色耳环、象牙色丝绸套装和半透明橙色丝巾的参考。创作一个新的高端时尚镜头：白色石灰岩露台，俯瞰平静的土蓝色地中海。她站在画面右侧的浅色石栏旁，橙色丝绸在海风中向左侧优雅飘动。镜头以平视角度缓慢侧移，她望向地平线。晴朗温暖的阳光，自然透亮的皮肤，粉蓝色天空，优雅的象牙色与陶土色调，真实的织物，一镜到底。声音：轻柔的海浪和微风。无对白，无音乐，无文字或标志。
   ```

4. 将 `@[人物参考图]` 替换为图片引用：删除占位符，在原位置输入 `@`，选择你添加的参考图片。
5. 将**比例**设为 **16:9**，**时长**设为 **5 s**，**清晰度**设为 **720p**。可选地，在**高级设置**中将**速度**设为 **Fast** 以加快预览。
6. 点击**生成**并等待任务完成。打开结果，对照参考图检查人物面部、服装和丝巾。

   ![以庭院视频的一帧为参考，在海边露台生成新的时尚视频](/images/manual/use-cases/minimax-h3-reference-result.jpg#bordered)

## 查找和下载视频

**Create** 按生成任务分组展示结果，**素材库**存放你的视频和保存的帧。

### 查找视频

根据你记得的信息选择查找位置：

- 按提示词：进入 **Create**，在**结果**中使用**搜索提示词**，或用**筛选**缩小范围。
- 按名称：进入**素材库**，选择**视频**，使用**搜索名称**，并用来源筛选缩小范围。

### 下载视频

- 单个视频：从**结果**或**素材库**打开，点击播放器下方的**下载**，保存到电脑。
- 多个视频：进入**素材库**，选择**视频**，勾选需要的视频，点击**下载**。

## 常见问题

### 为什么首次生成耗时更长？

应用会在生成前加载模型。如果模型尚未准备完成，打开**设置** > **打开模型控制台**查看，并在**结果**中关注任务状态。更高的清晰度和更长的时长也需要更多时间。

### 为什么 References 模式下无法点击生成？

至少添加一张参考图片或一个参考视频，并输入提示词。检查**添加媒体**旁显示的文件数量、大小和时长限制。

### 可以调整底层工作流吗？

打开**设置**，找到**在 ComfyUI 中打开工作流**。选择 **Text**、**Frames** 或 **References** 对应的工作流，需要时选择对应的快速版本，即可打开节点编辑器。

### MiniMax H3 和 FastH3 有什么区别？

MiniMax H3 提供两种速度设置：

- **Quality priority**：**Text**、**Frames** 和 **References** 均使用 20 个生成步数。
- **Fast**：使用 Lightning LoRA 减少生成时间，**Text** 和 **Frames** 为 8 步，**References** 为 4 步。

FastH3 是另一个使用八步蒸馏模型的应用。想快速尝试创意、再对满意的版本投入更多时间时，选择 MiniMax H3。想以最高效率尝试大量不同提示词和动作时，选择 FastH3。两者都支持文字、帧和参考素材。
