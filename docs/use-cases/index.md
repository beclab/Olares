# Use cases

Use cases are end-to-end guides for running popular open-source apps on Olares, from local AI and private media servers to self-hosted workspaces and developer tools. Pick a category or search by keyword to find an application, then open its full step-by-step guide.

:::tip Using an AI agent on your own computer?
You can use your existing agent to help set up apps, deploy models, and troubleshoot Olares. Follow [Use Olares CLI with AI agents](../developer/cli-install.md) to install Olares CLI and Agent Skills on that computer and log in. You can also ask your agent:

```plain
Install Olares CLI and Agent Skills, then help me log in to manage my Olares.
```

Agent apps running on Olares already include Olares CLI and Agent Skills. Follow the app's guide to get started.
:::
